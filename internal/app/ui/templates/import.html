The file

The first line names the columns, in any order. Each row after it is one person, found by their user id.

ColumnHolds
user_idRequired. The person's user id, such as an employee or student number.
groupsRequired. The slugs of the groups they join, separated by semicolons; may be empty.
emailCreates a user when nobody has the user id. Without it, the user id is pre-assigned to the groups listed and the person joins them on first sign-in. Replaces the email of someone who exists.
first_name, last_nameOptional names. A new user without them is called by their email; given for someone who exists, they replace theirs.
expires_atOptional date, like 2030-06-30, when the account ends. Empty is never for a new user and leaves someone who exists as they are.

For example

user_id,groups,email,first_name,last_name
100234,staff;lab,ann.smith@example.com,Ann,Smith
100871,staff,,,

New users have no door code and no password: they choose a code when they first sign in. A new user whose user id is on a group's pre-assigned list joins that group too, whether they are imported, created by an administrator, or sign in for the first time. Empty values leave someone who exists as they are. Importing the same file twice is safe.
