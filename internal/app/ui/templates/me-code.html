Door commands

As a door commander you can change what a door does from its keypad. Type your whole code, then *, then one digit that says which command, then any minutes it takes, then the submit key, usually #. The door asks the server, which carries out the command only for a door commander’s code and logs it under your name. A code never holds a *, so everything after the first * is the command, whatever the length of your code.

DigitTypeWhat it does
1code *1 minutes #Open mode: the door unlocks for anyone at a keypress, from now for 1 to {{.MaxMinutes}} minutes.
2code *2 minutes #Locked mode: only door commanders get in, from now for 1 to {{.MaxMinutes}} minutes. Locked mode wins over open mode while both are set.
0code *0 #Clear: ends every open or locked mode set on this door that is in force now, from the keypad or the door’s page. The door goes back to its schedules.
9code *9 #Reboot: restarts the door’s controller, as below.

Minutes are written as a plain number with no leading zero: 30, not 030. 0 and 9 take nothing after them. Any other digit, or anything else after the *, is refused.

You typeWhat happens

What the door does

  • Accepted: the strike releases for a few seconds, as when your code lets you in.
  • Refused: the door stays locked and nothing else happens: a mistyped command, minutes out of range, or a reboot too soon. The server logs why, and your entries list it.
  • A door that cannot reach the server refuses every entry, commands included, and none is carried out later.
  • The door has no display or sound of its own, so the strike is the only sign.

How long it lasts

  • Open or locked mode starts when the server accepts it and ends by itself once its minutes are up, at most {{.MaxMinutes}} minutes, a day.
  • It ends sooner with *0 at the door, or from the door’s page under Overrides, where it is listed as a keypad command.
  • While a door is in open mode, from a command or a schedule, any key unlocks it and nothing typed reaches the server, so no command can be given there: end an open mode early from the door’s page.
  • To swap locked mode for open mode, clear it with *0 first.

Reboot

  • The strike releases to show it was accepted, then the controller restarts and connects again, usually within a minute. It stays locked while it restarts.
  • It comes back following its schedules, with any open or locked mode still in force.
  • A door can be rebooted from its keypad once in {{.RebootGapMinutes}} minutes, and not while it is installing a firmware update.
  • A door that cannot reach the server cannot be rebooted from its keypad.
